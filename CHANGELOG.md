## [1.0.0] - 2025-10-23

### Добавлено

- ✅ REST API сервер на Node.js + Express

- ✅ Эндпоинт поиска пользователей `/api/search-users/:username`
- ✅ Эндпоинт информации о пользователе `/api/user/:steamId`
- ✅ Эндпоинт списка игр `/api/user-games/:steamId`
- ✅ Эндпоинт инвентаря `/api/inventory/:steamId/:appId`
- ✅ Эндпоинт цен предметов `/api/item-price/:appId/:marketHashName`

## Известные проблемы

### v1.0.0

#### Backend
- Нет rate limiting для API запросов
- Отсутствует кеширование ответов Steam API
- Нет логирования запросов

#### Mobile
- Медленная загрузка больших инвентарей (>500 предметов)
- Нет обработки потери интернет-соединения
- Изображения предметов не кешируются локально

#### Общее
- Профиль и инвентарь должны быть публичными
- Некоторые предметы могут не иметь цены
- Steam API имеет лимиты на количество запросов

## Как обновляться

### Backend

```bash
cd backend
git pull
npm install
npm start
```

### Mobile

```bash
cd mobile
git pull
npm install

# Для обновления на устройстве
npm run android
```
