# 📱 Руководство по публикации приложения

## Подготовка приложения к публикации

### 1. Обновите версию приложения

Откройте `mobile/android/app/build.gradle` и обновите:

```gradle
defaultConfig {
    versionCode 1      // Увеличивайте для каждого обновления
    versionName "1.0"  // Версия для пользователей
}
```

### 2. Создайте подписанный APK/AAB

#### Создание keystore (делается один раз)

```bash
keytool -genkeypair -v -storetype PKCS12 -keystore my-release-key.keystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000
```

Вас попросят ввести:
- Пароль keystore (запомните его!)
- Ваши данные (имя, организация и т.д.)

**⚠️ ВАЖНО**: Сохраните файл keystore и пароли в безопасном месте! Без них вы не сможете обновлять приложение!

#### Настройка подписи

1. Переместите `my-release-key.keystore` в папку `mobile/android/app/`

2. Создайте/отредактируйте `mobile/android/gradle.properties`:

```properties
MYAPP_RELEASE_STORE_FILE=my-release-key.keystore
MYAPP_RELEASE_KEY_ALIAS=my-key-alias
MYAPP_RELEASE_STORE_PASSWORD=ваш_пароль
MYAPP_RELEASE_KEY_PASSWORD=ваш_пароль
```

3. Обновите `mobile/android/app/build.gradle`:

```gradle
android {
    ...
    signingConfigs {
        release {
            if (project.hasProperty('MYAPP_RELEASE_STORE_FILE')) {
                storeFile file(MYAPP_RELEASE_STORE_FILE)
                storePassword MYAPP_RELEASE_STORE_PASSWORD
                keyAlias MYAPP_RELEASE_KEY_ALIAS
                keyPassword MYAPP_RELEASE_KEY_PASSWORD
            }
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled enableProguardInReleaseBuilds
            proguardFiles getDefaultProguardFile("proguard-android.txt"), "proguard-rules.pro"
        }
    }
}
```

#### Сборка Release APK

```bash
cd mobile/android
./gradlew assembleRelease
```

APK будет здесь: `mobile/android/app/build/outputs/apk/release/app-release.apk`

#### Сборка AAB для Google Play

```bash
cd mobile/android
./gradlew bundleRelease
```

AAB будет здесь: `mobile/android/app/build/outputs/bundle/release/app-release.aab`

## 📲 Публикация в RuStore

### Преимущества RuStore:
- ✅ Бесплатная регистрация
- ✅ Бесплатная публикация
- ✅ Российская аудитория
- ✅ Быстрая модерация

### Шаги публикации:

#### 1. Регистрация

1. Перейдите на https://console.rustore.ru/
2. Войдите через VK или другой способ
3. Заполните информацию о разработчике

#### 2. Создание приложения

1. Нажмите "Создать приложение"
2. Заполните основную информацию:
   - **Название**: Inventory Checker
   - **Короткое описание**: Просмотр инвентаря Steam
   - **Полное описание**: (см. ниже)
   - **Категория**: Инструменты / Разное
   - **Возрастной рейтинг**: 12+

#### 3. Описание приложения

**Короткое описание (80 символов):**
```
Просматривайте инвентарь Steam пользователей и узнавайте цены предметов
```

**Полное описание:**
```
Inventory Checker - удобное приложение для просмотра инвентаря Steam.

🎮 Возможности:
• Поиск пользователей Steam по нику
• Просмотр профилей пользователей
• Просмотр инвентаря CS:GO, Dota 2, TF2 и других игр
• Актуальные цены предметов с торговой площадки Steam
• Подробная информация о каждом предмете
• Современный интерфейс в стиле Steam

💡 Как использовать:
1. Введите ник пользователя Steam
2. Выберите пользователя из результатов
3. Выберите игру для просмотра
4. Нажмите на предмет для просмотра деталей и цены

⚠️ Важно: Профиль и инвентарь пользователя должны быть публичными.

Приложение использует официальный Steam Web API для получения данных.
```

#### 4. Скриншоты

Сделайте 4-8 скриншотов приложения:
1. Главный экран (поиск)
2. Список найденных пользователей
3. Выбор игры
4. Инвентарь игры
5. Детали предмета с ценой

Требования:
- Формат: PNG или JPEG
- Минимум: 1280x720
- Соотношение: 16:9 или 9:16

#### 5. Иконка приложения

Создайте иконку 512x512 пикселей в формате PNG.

Можно использовать онлайн-сервисы для создания:
- Canva
- Adobe Express
- Figma

#### 6. Загрузка APK

1. Загрузите файл `app-release.apk`
2. Система автоматически проверит APK
3. Заполните информацию о версии

#### 7. Модерация

1. Проверьте всю информацию
2. Нажмите "Отправить на модерацию"
3. Дождитесь результатов (обычно 1-3 дня)
