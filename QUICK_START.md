# 🚀 Быстрый старт

## Шаг 1: Получите Steam API ключ

1. Перейдите на https://steamcommunity.com/dev/apikey
2. Войдите в Steam
3. Заполните форму и получите ключ

## Шаг 2: Настройте backend

```bash
cd backend
npm install
copy .env.example .env
```

Откройте `backend/.env` и вставьте ваш Steam API ключ:
```
STEAM_API_KEY=ваш_ключ_здесь
```

## Шаг 3: Запустите backend

```bash
npm start
```

Сервер запустится на http://localhost:3000

## Шаг 4: Настройте мобильное приложение

В новом окне терминала:

```bash
cd mobile
npm install
```

## Шаг 5: Запустите приложение на Android

### Для эмулятора:

1. Откройте Android Studio
2. Запустите AVD (Android Virtual Device)
3. Вернитесь в терминал и выполните:

```bash
npm run android
```

### Для реального устройства:

1. Включите режим разработчика на телефоне
2. Включите отладку по USB
3. Подключите телефон к компьютеру
4. Измените адрес сервера в `mobile/src/config/api.js`:
   ```javascript
   export const API_BASE_URL = 'http://IP_ВАШЕГО_ПК:3000';
   ```
5. Запустите: `npm run android`

## 🎉 Готово!

Приложение должно запуститься на вашем устройстве.

## ⚡ Автоматический запуск (Windows)

Просто запустите файл `start-dev.bat` - он автоматически запустит backend и мобильное приложение.

## 🐛 Проблемы?

### Сервер не запускается
- Проверьте, что порт 3000 свободен
- Убедитесь, что Steam API ключ правильный

### Приложение не подключается к серверу
- Убедитесь, что backend запущен
- Для реального устройства: проверьте IP адрес в `api.js`
- Убедитесь, что телефон и компьютер в одной сети

### Ошибки при сборке
```bash
cd mobile/android
./gradlew clean
cd ../..
npm start -- --reset-cache
npm run android
```

## 📱 Как использовать приложение

1. **Поиск пользователя**: Введите ник Steam пользователя
2. **Выбор пользователя**: Нажмите на найденного пользователя
3. **Выбор игры**: Выберите игру для просмотра инвентаря
4. **Просмотр предмета**: Нажмите на любой предмет для просмотра деталей и цены
